# TablacusMac

Tablacus Explorer を参考にした、macOS 向けのタブ型ファイラーです。SwiftUI で作っており、外部依存はありません。

## 主な機能

- タブ（⌘T で開く、⌘W で閉じる）と、戻る・進む・上の階層への移動
- 分割レイアウトの切り替え: 1画面 / 左右2画面 / 上下2画面 / 3列 / 2×2（⌘⌥1〜5）
- コピー・カット・ペースト、ドラッグ&ドロップ、名前変更、新規フォルダ、ゴミ箱
  - 同じ名前のファイルをコピーすると「名前-番号」の別名を付ける
  - ゴミ箱への移動は Finder に依頼するため、Finder の「戻す」で元に戻せる
- 表示中のフォルダを名前で絞り込む（⌘F）
- サイドバーの「よく使う項目」をドラッグ&ドロップで追加・並べ替え・削除できる
- 右クリックメニューの「パスをコピー」「Finderで表示」「WezTermで開く」
- 前回終了時のレイアウト・タブ・操作中のペインを起動時に復元する
- 隠しファイルも常に表示する
- フォルダの開閉（▶ / → / ←）、クイックルック、情報を見る、複製、エイリアス作成、圧縮など Finder の主なメニューとキー操作

## 動作環境

- macOS 14 以降
- Swift 6（Command Line Tools だけでもビルドできる）
- 「WezTermで開く」を使う場合は [WezTerm](https://wezterm.org/)

## ビルドと実行

```sh
make run    # swift run で起動する
make test   # テストを実行する
make app    # TablacusMac.app を作る
```

`make app` は、初回だけ自己署名の証明書「TablacusMac Local Signing」を作ってログインキーチェーンに入れ、その証明書で署名します。アドホック署名ではビルドするたびに別のアプリとして扱われ、フォルダへのアクセスや Finder の操作の許可がリセットされてしまうためです。

アイコンの元データ（`Resources/AppIcon.svg`）を変えたときは、`make icon` で `AppIcon.icns` を作り直します。これには `rsvg-convert` が必要です（`brew install librsvg`）。

## キー操作

| 操作 | キー |
|---|---|
| 新しいタブ / タブを閉じる | ⌘T / ⌘W |
| 新規フォルダ | ⇧⌘N |
| カット / コピー / ペースト | ⌘X / ⌘C / ⌘V |
| すべてを選択 | ⌘A |
| 絞り込み | ⌘F |
| 開く | ⌘↓ / ⌘O |
| フォルダを開く / 閉じる（一覧の中で） | → / ← |
| クイックルック | Space / ⌘Y |
| 情報を見る | ⌘I |
| 複製 / エイリアスを作成 | ⌘D / ⌘L |
| 項目をここに移動 / パス名をコピー | ⌥⌘V / ⌥⌘C |
| 名前を変更 | Return / F2 |
| ゴミ箱に入れる | ⌫ / ⌘⌫ |
| 戻る / 進む / 上の階層 | ⌘[ / ⌘] / ⌘↑ |
| 前のタブ / 次のタブ | ⇧⌘[ / ⇧⌘] |
| フォルダへ移動（パス欄へ） | ⇧⌘G |
| 書類 / デスクトップ / ダウンロード / ホーム | ⇧⌘O / ⇧⌘D / ⌥⌘L / ⇧⌘H |
| iCloud Drive / アプリケーション / ユーティリティ | ⇧⌘I / ⇧⌘A / ⇧⌘U |
| 再読み込み | ⌘R |
| レイアウトの切り替え | ⌘⌥1〜5 |
